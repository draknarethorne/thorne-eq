# ROADMAP v0.1.0 — Foundation Milestone

> **Superseded by `.docs/ROADMAP.md`** (the master phased plan). Kept as Phase 0/1 detail.

## Milestone Intent

Establish the planning, constraints, and first technical scaffolding for a Quarm-compatible hybrid capability system.

## Success Criteria

- Clear constraints documented and agreed.
- Initial architecture approved for prototype implementation.
- First archetype prototype path specified with explicit limits.
- Feature-flag strategy defined for safe rollout.

## Workstreams

## 1) Design Baseline

- [ ] Finalize affinity taxonomy (initial 4-6 tracks).
- [ ] Define spell family taxonomy and naming conventions.
- [ ] Define first archetype profile (warrior+druid+necromancer influence).

## 2) Rules & Constraints

- [ ] Codify hard prohibitions (never-open spell families).
- [ ] Document role-protection guardrails (tank/heal/control boundaries).
- [ ] Define progression gates and unlock cadence.

## 3) Data Model Draft

- [ ] Draft migration plan for affinity + profile tables.
- [ ] Define rollback strategy for failed experiments.
- [ ] Add feature flags for staged activation.

## 4) Prototype Plan

- [ ] Select first limited test cohort.
- [ ] Define observability metrics and baseline snapshots.
- [ ] Establish pass/fail criteria for phase expansion.

## 5) Operations & Governance

- [ ] Define change proposal format for new affinities/families.
- [ ] Define balancing review cadence.
- [ ] Define release communication template.

## Deferred to v0.2.x+

- Broad multi-archetype rollout
- Advanced Zeal-enhanced UX feedback loops
- Automated progression tuning models

## Versioning

- Current: `0.1.0-dev`
- Target release marker: `v0.1.0-foundation`
